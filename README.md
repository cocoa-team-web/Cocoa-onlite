# Cocoa Online — Город игроков

Небольшой 2D-прототип онлайн-города для Chrome и Android-планшетов.

## Что есть
- 2D-город, здания, дороги, мини-карта и собираемые кристаллы.
- Управление на сенсорном экране: джойстик и прыжок.
- WASD/стрелки и пробел на клавиатуре.
- WebSocket-сервер: имена, позиции игроков, чат.
- Лимит комнаты — 20 подключений.
- `/health` для проверки состояния сервера.
- `render.yaml` для развёртывания на Render Blueprint.

## Развёртывание на Render с Android-планшета
1. Скачай ZIP и распакуй его в приложении «Файлы»/архиватор.
2. Открой GitHub в Chrome и создай новый репозиторий, например `cocoa-online-city`.
3. Загрузи в корень репозитория файлы `index.html`, `style.css`, `game.js`, `server.js`, `package.json`, `render.yaml`, `README.md`. Не загружай их в дополнительную вложенную папку.
4. Открой https://dashboard.render.com/blueprints/new?repo= и подключи репозиторий через GitHub, либо в Render создай новый Blueprint и выбери репозиторий с `render.yaml`.
5. Проверь параметры: Build Command `npm install`, Start Command `npm start`, Health Check Path `/health`, план Free. Нажми Apply/Create.
6. Дождись статуса `Live`. Открой адрес сервиса вида `https://cocoa-online-city.onrender.com`. Сайт и WebSocket используют один домен; отдельный адрес сервера вводить не нужно.
7. Проверь `https://ТВОЙ-АДРЕС.onrender.com/health`. Должен появиться JSON с `"ok":true`.
8. Открой сайт в двух браузерах/устройствах, нажми «Играть онлайн» на обоих и проверь, что видны оба игрока.

## Важно
- Этот проект подготовлен как исходники, но перед публикацией нужно реально развернуть и проверить его в браузере.
- Бесплатный сервис Render может засыпать при простое, поэтому первое подключение после паузы может занимать время.
- Комната ограничена 20 WebSocket-подключениями; это прототип, не масштабированный продакшен.
- Позиции проходят базовую серверную проверку, но игра не является защищённой от читов. Подбор кристаллов пока локальный и не синхронизируется между игроками.
- Для публикации в Яндекс Играх отдельно проверь актуальные требования платформы и добавь требуемую интеграцию SDK/проверки. Наличие этих файлов само по себе не означает, что игра уже опубликована.
